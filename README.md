## 🧠 About me

I like understanding what happens *under the hood*: how source code turns into machine instructions, how memory is laid out, what a compiler actually does, and how an OS runs it all.

- 🔧 **Focus:** low-level and systems programming
- 💻 **Write:** Assembly, C++, C
- 🌱 **Learning:** Rust, assembly, OS internals, networking
- 🐧 **Environment:** Linux, Git
